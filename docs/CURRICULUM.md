# Curriculum

The 90-day Python plan is described in **`docs/PLAN_90_DAY.md`** (weekly rhythm, mock spec, week-by-week problems, practical programs). The app reads **`content/curriculum.json`** (version 2), which is generated by **`scripts/build_curriculum.py`**: change the script and regenerate, never hand-edit the JSON. `npm run validate` checks it. The shape is documented in `docs/CONTENT_SCHEMA.md`.
